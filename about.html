About the Project

This website was created as part of a CSS3 learning assignment. Its purpose is to practice styling HTML elements with CSS rules.

A single external stylesheet controls the typography, background colors, spacing, and layout of all three pages.

Technologies Used

  • HTML5 for page structure
  • CSS3 for styling and layout
  • Responsive design for smaller screens
  • Accessibility testing with WAVE
